# Readwise Killer

A superior, LLM-free Readwise alternative built by Dinesh.

## Overview
This project aims to build a robust, free-tier deployable alternative to Readwise. It focuses on core functionalities like highlight syncing, spaced repetition, and active recall without relying on expensive LLM APIs.

## Tech Stack
- **Frontend:** React
- **Backend/Database:** Firebase (Firestore, Auth, Hosting)
- **Algorithms:** Custom Python/JS implementations for Spaced Repetition (SuperMemo-2 based) and NLP (Readability.js for parsing).

## Features (Planned)
- User Authentication
- Highlight Ingestion (Manual & Parsing)
- Spaced Repetition Daily Reviews
- Read-it-later functionality

## Deployment
Designed to be deployed on Firebase's free tier.
